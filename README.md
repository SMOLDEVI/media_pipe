# Лабораторная работа №5: Захват видеопотока и выделение скелетной модели человека

Данный проект реализует практический пайплайн захвата видеопотока с веб-камеры, выделения скелетной модели человека с помощью библиотеки **MediaPipe Pose (BlazePose)**, визуализации ключевых точек в реальном времени, сохранения извлеченных данных в форматы **JSON/CSV**, записи видео в **MP4** и интерактивного построения **3D-скелета в Matplotlib**.

## 3. Запуск и порядок работы

### Этап 1: Запуск захвата видеопотока и детекции позы
Запустите основной скрипт:
```powershell
.\.venv\Scripts\python.exe capture_skeleton.py
```

* **Что происходит:**
  1. Открывается веб-камера (по умолчанию индекс `0`).
  2. Инициализируется модель `MediaPipe Pose` (`static_image_mode=False`, `smooth_landmarks=True`).
  3. Каждый кадр конвертируется из **BGR** в **RGB** для нейросети.
  4. Нейросеть находит 33 ключевые точки скелета.
  5. Поверх видеопотока зелеными маркерами рисуются суставы, а синими линиями — анатомические связи (кости).
  6. На кадре отображается полупрозрачный HUD (FPS, статус детекции, координаты носа, статус записи).
  7. Ведется автоматическая запись размеченного видео в `output_skeleton.mp4`.

* **Горячие клавиши в окне просмотра:**
  - `q` — Завершить работу, сохранить `output_skeleton.mp4`, `skeleton_data.json` и `skeleton_data.csv`.
  - `r` — Включить / выключить запись видео.
  - `s` — Сделать мгновенный скриншот текущего кадра со скелетом (сохраняется в `screenshot_frame_XXXX.png`).
  - `h` — Скрыть / показать HUD-плашку.

* **Параметры командной строки:**
  ```powershell
  # Запуск от конкретной камеры или видеофайла:
  .\.venv\Scripts\python.exe capture_skeleton.py --source 0
  .\.venv\Scripts\python.exe capture_skeleton.py --source "my_video.mp4"

  # Изменение сложности модели: 0 (быстро), 1 (баланс, по умолчанию), 2 (макс. точность)
  .\.venv\Scripts\python.exe capture_skeleton.py --complexity 2
  ```

### Этап 2: 3D-визуализация скелета в Matplotlib

После завершения захвата (нажатия `q`) сохраненные пространственные координаты `(x, y, z)` загружаются в 3D:

#### 1. Интерактивный режим со слайдером (рекомендуется для исследования):
```powershell
.\.venv\Scripts\python.exe visualize_3d.py
```
* Откроется трехмерный график с ползунком выбора кадра внизу.
* График можно вращать зажатой левой кнопкой мыши, приближать и удалять колесиком.
* Отображаются подписи ключевых суставов (Нос, плечи, локти, кисти, бедра, колени, лодыжки).

#### 2. Режим анимации во времени:
```powershell
.\.venv\Scripts\python.exe visualize_3d.py --mode animate
```

#### 3. Быстрый экспорт 3D-рендера в PNG (для отчета):
```powershell
.\.venv\Scripts\python.exe visualize_3d.py --mode export_only --output-png skeleton_3d_render.png
```

## 4. Теоретические сведения и ответы на контрольные вопросы

### Архитектура BlazePose
MediaPipe Pose использует двухэтапную архитектуру **BlazePose**:
1. **Детектор области интереса (ROI / Pose Detector):** находит человека в кадре и определяет границы ограничивающего прямоугольника с ориентацией тела.
2. **Трекер ключевых точек (Landmark Regression Model):** внутри вырезанной и выровненной области предсказывает 33 анатомические точки.
* Параметр `static_image_mode=False` критически важен: детектор запускается только на первом кадре или при потере человека; на остальных кадрах работает легкий и быстрый трекер на основе положения ROI из предыдущего кадра, что обеспечивает высокую производительность реального времени (>30 FPS) и отсутствие мерцания.
* `smooth_landmarks=True` применяет фильтрацию для сглаживания джиттера (дрожания) суставов.

### Координаты точек
Для каждой из 33 точек возвращаются 4 атрибута:
- `x`, `y` — пространственные координаты, нормализованные в диапазон $[0, 1]$ относительно ширины и высоты кадра. Чтобы перевести в пиксели: $X_{px} = x \cdot W$, $Y_{px} = y \cdot H$.
- `z` — относительная глубина сустава относительно центра таза (меньшее значение — ближе к камере).
- `visibility` — оценка уверенности от $0.0$ до $1.0$, что сустав виден на изображении, а не перекрыт телом или другими объектами.

### Ключевые индексы точек MediaPipe Pose:
| Индекс | Часть тела | Индекс | Часть тела |
| :---: | :--- | :---: | :--- |
| **0** | Нос | **15, 16** | Запястья (левое / правое) |
| **11, 12** | Плечи (левое / правое) | **23, 24** | Бедра (левое / правое) |
| **13, 14** | Локти (левые / правые) | **25, 26** | Колени (левое / правое) |
| **27, 28** | Лодыжки (левая / правая) | **29, 30** | Пятки |
